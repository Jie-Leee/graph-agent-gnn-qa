# A 数据质量处理约定与版本边界

适用版本：`data/processed/manifest.json` 中模板 v4、种子 42 的固定版本，
train/validation/test 为 2000/200/300 条。原始 1250 个查询组及金标保持不变。
本次补充质量标记、语义初审和交接检查，不依据模型测试成绩修改题目或答案。

## 1. 答案的真值范围

标准答案定义为：只在原始 `train.txt` 中，从给定主题沿指定两步关系可达的全部
实体 ID。它是图内闭集答案，不声称现实世界事实完整、时效正确或覆盖全部可能
答案。题面中的 every 均按这个闭集解释。原始 valid/test 边不加入可见图。

本任务是已知主题、已知图谱上的自构模板 QA。主实验使用给定主题 ID；实体
定位作为 B 的额外设置独立报告。四种模板和关系白名单限制了语言多样性，不能
将本版本称为天然自然语言多跳 QA 或未知事实泛化基准。

## 2. 同名实体

实体身份始终由 ID 决定。名称相同不代表实体相同，名称不同也不能直接判断身份。
质量标记同时记录名称在完整原始映射表中的候选 ID，以及候选是否在可见训练图中。
匹配仅归一化 Unicode 大小写和连续空白，不擅自删标点或合并同名 ID。

本版本保留原题与 ID，已知主题模式通过 ID 指定实体。B 如测试仅依赖题面的实体
定位，必须保留多个候选并处理上下文消歧，另报定位表现；不能将给定 ID 记为
预测成功。D 的纯 LLM 模式只从问题文本作答，名称歧义是需要在报告说明的限制。

答案中同名不同 ID 也不自动合并。E 应优先按实体 ID 比较集合。如果 LLM 只生成
名称，名称到 ID 的映射可能一对多；不得直接将同名标签视为已唯一匹配正确 ID。

## 3. 源名称后缀与显示文字

`Actor-GB`、`Pacific Time Zone-US` 等来自源名称映射，属于名称质量提示。本版
保留原始名称和实体 ID，不在冻结数据中批量替换，也不把后缀当成新的关系或身份。
展示层可另提供更自然的显示名，但必须同时保留原名、ID 和转换规则；展示名清洗
不改变答案集合。移除后缀不能作为实体合并依据。质量标记会列出相关原名供检查。

## 4. 地点粒度、包含关系与类型

London 与 Marylebone、New York City 与 Manhattan 等可能是不同层级的实体，
不得因包含关系、名称相似或地理接近而合并或替换金标。图中的 contains 可以连接
地区、学校、机构等不同类型，不能将它自动解释为“城市列表”。本版保留 source
关系语义与原 ID，将表述生硬或粒度混合的样本记入语义初审记录。

初审的 `train-00400` 甚至包含 Real Madrid C.F. 这类俱乐部名称，说明源 contains
的尾实体不保证符合题面“地理地点”的通常含义。该样本保留风险标记，不能将其
计作自然语言语义已无问题。使用本版时明确限定为源图关系组合；自然语言质量
升级应另发版本，统一修订 contains 表述并复核全部相关题目。

`nationality` 本版表述为 country of citizenship，二者的现实语义并不在所有
情境下等价，应将该映射视为已披露的模板近似，不据此作现实法律身份判断。
若要改成更保守的“nationality associated with”，须发布新版本并统一重跑，不能
在同一组模型的测试过程中临时改题。

## 5. 一跳邻居与两跳难度

题目由两步关系构造，不保证每个答案在无类型图上的最短距离恰好为 2。
质量标记区分“至少一个金标答案也是一跳出邻居”和“全部金标答案均为一跳出邻居”。
这些标记不证明题目错误，也不证明其他关系的一跳边在语义上回答了题目。

本版本保留这类样本。E 在整体结果之外可分别统计含/不含一跳答案的查询组，
不得将某个切片替代既定主测试集。不能按模型表现删题，也不能用金标路径或答案
指导 B 在测试阶段补候选。关系集中度筛选是启发式，不能保证没有可猜测部分答案
的捷径，例如“作曲家的职业”中可能出现 Composer。

## 6. 质量元数据的用途

`data/quality/` 中的标记、样本和审阅记录用于 A 的质量审查及 E 的事后分层分析。
它们可能包含答案、路径或由答案推导的标记，不能作为测试检索、Agent 提示词、
工具决策或 GNN 测试候选生成的输入。推理入口仍只读取 `*.questions.jsonl`
并通过 `load_questions()` 获得 `Question`。

推理过程中 B 从可见训练图自行检索出来的真实证据可以用于 text/gnn 模式。
需要隔离的是预先附带的标准答案、标准关系路径和标准证据，而不是禁止使用图谱。

## 7. 冻结、修正与职责结束条件

原数据清单的输入/输出哈希标识本次基线。新的质量标记不覆盖原 QA 文件。
确认数据缺陷后，以新版本记录修改原因、影响题目、参数和哈希；所有比较方案
统一使用相同新版本，测试集不用于反复调模型或挑选有利样本。

A 的本次收尾交付为：覆盖全部关系组合的可追溯模型语义初审、全查询组质量标记、
本处理约定、A 侧可执行接口验收，以及清楚列出的剩余下游确认状态。模型语义
初审不等同于独立人工专家标注。B/D 成员是否完成实际接入，由他们运行和确认；
A 无法替他们确认尚未实现的模块或代填人工验收结果。

交付冻结后，A 继续负责数据缺陷修复、必要的接口解释、版本变更记录和自己的
汇报材料。B 的检索优化、C 的模型训练、D 的 Agent 实现及 E 的正式实验由各自
负责人推进。只有出现具体数据问题、接口变动或共同决定更新数据时，才需要 A
重新开发或发布版本；不需要在队友每次运行时重新造题或重新划分。
