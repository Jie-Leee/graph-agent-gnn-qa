# Graph Agent 五人分工与一周安排

五人一周完成项目，展示共 25 分钟，每人约 5 分钟、约 3 页 PPT。E 为组长，其余姓名待填写。

| 成员 | 负责内容 | 交付 | 汇报 |
|---|---|---|---|
| A 数据 | FB15k-237、实体名称、QA 清洗与划分，检查重复和泄漏 | 数据脚本、QA、统计与样例 | 0–5 分钟：任务与数据 |
| B 图检索 | 图索引、实体定位、两跳子图与证据路径 | 查询工具、子图、召回和耗时 | 5–10 分钟：检索与证据 |
| C GNN | 小型 GAT 训练、候选打分、五组消融 | 代码、权重、曲线、配置输出 | 10–15 分钟：模型与训练 |
| D Agent | LLM API、自主查询决策、工具循环、三种模式 | 调用日志、Demo、备用录像 | 15–20 分钟：流程与演示 |
| E 组长 | 统一评测、实验、联调、PR 审核合并与排练 | 结果图表、整合版本、失败分析 | 20–25 分钟：实验与结论 |

每人编写自己的代码、运行说明和 PPT，组长统一样式与衔接。排练时每人争取控制在 4 分 40 秒。

## 进度

1. 第 1 天：确认数据来源、证据融合要求和接口；10 题跑通检索到回答。
2. 第 2 天：交付数据与查询工具；跑通纯 LLM 和文本检索模式；确认 GNN 小样本训练正常。
3. 第 3 天：接入 GNN，三种模式首次完整联调，在验证集检查召回和日志。
4. 第 4 天：完成五种 GNN 配置的训练和验证，固定提示词与检索设置。
5. 第 5 天：冻结功能，最终测试，整理结果与失败分析。
6. 第 6 天：拼接 PPT，完整排练至少两次，录制备用演示。
7. 第 7 天：展示前验收与缓冲，只修复影响展示的问题。

## 实验范围

三组基线：纯 LLM、Agent＋图谱文本检索、Agent＋图谱检索＋GNN。固定大模型、测试集和上下文预算。指标包括答案正确率或 F1、检索召回率、缺乏证据的作答比例和耗时。

五种配置：2 层 mean（主配置）、1 层 mean、3 层 mean、2 层 sum、2 层 max。聚合指图级聚合。优先本地 CPU 小型 GNN＋LLM API；首日确认课程允许此方式与证据融合方案。

`main` 为整合版本，加五个工作分支共六个分支。每人同步最新 main，在自己的分支开发、运行、提交和推送，然后发 PR，由组长审核并合并。PR 写清改动、运行方法和验证结果；不直接推 main，不强制推送公共分支。修改公共接口先沟通。分支不是权限隔离。密钥保留在本地 `.env`，原始数据、模型权重和缓存不上传。
